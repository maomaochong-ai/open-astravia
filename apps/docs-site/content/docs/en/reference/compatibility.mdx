The open-source and commercial builds may expose different login, organization, marketplace, model, or remote capabilities. The installed settings page and the download page are the final source of truth.

Status labels mean: **Stable** is intended for normal use, **Beta** may change with platform or provider conditions, **Developer preview** is for development and validation, and **Internal-only** is outside the public contract.

When reporting a compatibility issue, include the Vetta version, build source, OS version, CPU architecture, network conditions, and the last successful step. Never upload credentials, pairing data, webhook URLs, or an unredacted project directory.

This page describes the public boundary of the current implementation. A download, tenant, or organization policy can hide more. After installation, the settings page and the download page decide what you actually have.

## Platform matrix

| Capability | Windows | macOS | Linux | Android | iPhone |
| --- | --- | --- | --- | --- | --- |
| Desktop workspace and Agent | Supported | Supported | Supported | — | — |
| Models, MCP, knowledge, batch, automation | Supported | Supported | Supported | — | — |
| Desktop IM gateway | Depends on the gateway build | Depends on the gateway build | Depends on the gateway build | — | — |
| SSH remote projects | Supported | Supported | Supported | — | — |
| Application snapshots | — | Supported | — | — | — |
| macOS iMessage | — | Beta | — | — | — |
| Pair a phone and continue sessions | As the computer | As the computer | As the computer | Supported | Supported on iOS 26 or later |
| Pair with a connection code | The computer can show one | The computer can show one | The computer can show one | Supported | Supported |
| View and control the computer desktop | As the controlled computer | As the controlled computer | As the controlled computer | Supported | — |

Phone columns describe the Vetta phone app. The desktop columns say whether that Desktop can be the paired computer or the SSH client. iPhone can scan a QR code, use a connection code, or enter a LAN address. It has no desktop picture.

## Build modes

| Mode | Main difference |
| --- | --- |
| Open source / serv-less | No Vetta Serv account, subscription, or remote model catalog. Local sessions, your own API keys, and the built-in capability catalog |
| Commercial / Vetta Serv | May include sign-in, organizations, subscriptions, the official marketplace, and a remote model catalog |

Both modes can include local sessions, plugins, themes, IM, and the knowledge base. The exact system plugins can still vary by build profile and tenant. The open-source build does not require sign-in.

## What the labels mean

- **Stable**: a normal user can follow the page. Behavior still follows the current release.
- **Beta**: it is in the client or gateway, but a third-party dependency, platform condition, or interface may still change.
- **Varies by platform**: it is an ordinary settings entry, while phone OS requirements, connection codes, and the desktop picture still differ by platform. Remote access is in this group. It is no longer a developer preview.
- **Internal-only**: outside this public site. Do not guess an internal path.

## Reporting a compatibility issue

Include:

- Vetta version, where the build came from, and the operating system version. For a phone, include the phone OS version too.
- CPU architecture, and whether a proxy or corporate network is in use.
- Whether the settings page shows the entry, and the last step that succeeded.
- A redacted error, the time, and the smallest steps that reproduce it.

Do not upload API keys, OAuth cookies, pairing QR codes, connection codes, passwords, webhook URLs, a full project directory, or an unredacted diagnostics package. For a security issue, read [security and data boundaries](/reference/security-and-data/) first.

---
title: Settings map
description: Find the main settings areas and understand which controls affect models, permissions, integrations, and local data.
---

| Area | Controls |
| --- | --- |
| General | Startup guide, diagnostics, language, appearance, and application behavior |
| Model configuration | Providers, credentials, model IDs, defaults, and thinking level |
| Agent | Execution defaults, permissions, context, and session behavior |
| Claw | IM channels, command handling, reply model, logs, and restart |
| Knowledge base | Source import, processing model, indexing, and history |
| Application environment | Bundled Node.js/Python runtimes and reinstall actions |
| Appearance and themes | Theme selection, custom theme sources, and preview |
| Remote control | Supported host pairing and remote session state |

When a feature is missing, check the build profile, operating system, and whether the feature is marked Beta or Developer preview. Do not infer an internal route from a stale screenshot.

Before exporting diagnostics, remove credentials, cookies, pairing data, webhook URLs, and private project contents.

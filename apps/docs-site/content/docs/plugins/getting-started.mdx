## 前置条件

- Bun、TypeScript 和 Vite。
- React 19。
- 用于安装和调试插件的 Vetta 桌面客户端。

安装当前公开版本：

```bash
bun add @vetta-org/plugin-sdk@^0.1.1
bun add -d @vetta-org/plugin-vite@^0.0.5 vite@^7 react@^19
```

## 配置构建

通过 `@vetta-org/plugin-vite` 配置 Module Federation：

```ts
import tailwindcss from "@tailwindcss/vite";
import { vettaPluginFederation } from "@vetta-org/plugin-vite";
import { defineConfig } from "vite";

export default defineConfig({
	plugins: [
		tailwindcss(),
		vettaPluginFederation({
			name: "my_plugin",
			entry: "./src/index.tsx",
			expose: "./plugin",
		}),
	],
	esbuild: { jsx: "automatic", jsxImportSource: "react" },
});
```

## 创建入口

```tsx
import { definePlugin } from "@vetta-org/plugin-sdk";

function MyPanel() {
	return <div className="p-3 text-sm text-foreground">插件已加载</div>;
}

export default definePlugin({
	activate(ctx) {
		ctx.ui.registerGlobalSlot({ id: "root", component: MyPanel });
	},
});
```

<Callout title="不要在模块顶层创建 JSX" type="warn">
  Module Federation 的共享 React 依赖在 bootstrap 后才可用。把 JSX 放在组件或 `activate()` 调用后的执行路径中。
</Callout>

## 构建与加载

按开发调试与正式发布选择路径：

<Tabs items={["开发调试", "发布安装"]}>
  <Tab value="开发调试">
    使用 `bunx vetta-plugin dev` 启动插件开发服务，再通过 Vetta 的开发链接加载。改动后可快速验证界面与工具注册，但发布前仍要执行生产构建并测试 ZIP 安装流程。
  </Tab>
  <Tab value="发布安装">
    <Steps>
      <Step>
        ### 生产构建

        运行 `bunx vite build`，生成 `dist/mf-manifest.json`、`remoteEntry.js` 和样式文件。
      </Step>
      <Step>
        ### 打包归档

        发布包应在归档根目录包含 `plugin.json` 和 `dist/`。
      </Step>
      <Step>
        ### 安装并启用

        在侧栏 **能力** 页打开 **添加能力 → 导入插件压缩包**，选择 ZIP；安装后在 **启用与权限** 对话框中启用并授权。
      </Step>
      <Step>
        ### 验证加载

        打开插件注册的界面或触发其工具，确认产物确实被宿主加载。
      </Step>
    </Steps>
  </Tab>
</Tabs>

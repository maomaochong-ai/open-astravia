## 构建模式

| 模式 | 主要差异 |
| --- | --- |
| 开源 / serv-less | 无 Vetta Serv 账户、订阅、官方目录和远程模型目录；使用本地会话、BYOK 和公开能力源 |
| 商业 / Vetta Serv | 可包含登录、组织、订阅、官方 Marketplace 和远程模型目录 |

两种模式都可以包含本地会话、插件、主题、IM 和知识库，但具体系统插件组合可能随构建 profile 和租户变化。

## 状态含义

- **稳定入口**：普通用户可以按页面步骤使用，行为仍以当前发布版本为准。
- **Beta**：已经进入客户端或网关，但第三方依赖、平台条件或接口仍可能变化。
- **Developer preview**：主要用于仓库开发和验证，不承诺所有下载包提供，也不承诺跨版本兼容。
- **Internal-only**：不属于公开站点范围，不应通过猜测内部路径使用。

## 提交兼容性问题

报告平台问题时提供：

- Vetta 版本、构建来源和操作系统版本。
- CPU 架构、是否使用代理或企业网络。
- 设置页是否显示目标入口，以及最后一个成功步骤。
- 已脱敏的原始错误、执行时间和最小复现步骤。

不要上传 API Key、OAuth Cookie、配对二维码、Webhook URL、完整项目目录或未脱敏诊断包。涉及安全问题时，先阅读[安全与数据边界](/reference/security-and-data/)。

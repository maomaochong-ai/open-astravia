项目决定一组工作的本地目录和长期背景；会话记录一次连续任务的消息、工具调用和结果。先选对项目，再开始会话，可以减少路径错误和上下文混乱。

## 选择从哪里开始

| 入口 | 适合场景 | 文件边界 |
| --- | --- | --- |
| 对话 | 咨询、无需固定项目的临时任务 | 不自动绑定具体项目目录 |
| 新建项目 | 在一个新目录中开始长期工作 | 新项目目录 |
| 打开项目 | 让 Vetta 处理已有本地目录 | 选择的目录 |
| 导入项目 | 恢复带 Vetta 会话和状态的项目包 | 导入后的项目目录 |

需要读取、编辑或生成文件时，选择对应项目。只是讨论方案、起草短文本或查询信息时，可以从「对话」开始。

- 一个项目可以有多个会话，它们共享项目目录，但各自保留对话和执行历史。
- 新目标通常新建会话；继续同一目标时恢复原会话。
- 分叉适合从既有上下文探索另一条路径，原会话不会被覆盖。
- 从列表移除项目不会删除磁盘目录；「删除项目」会永久删除目录，必须仔细阅读确认信息。

## 用项目指令保存长期约束

项目详情页可以编辑 `AGENTS.md`。它适合保存所有会话都需要遵循的规则，例如技术栈、测试命令、目录所有权和禁止操作。

```markdown
# 项目约束

- 使用 Bun，不切换包管理器。
- 修改认证模块后运行 `bun run test:auth`。
- 不修改 `generated/`，它由构建脚本生成。
```

不要把一次性任务、密钥或个人临时信息写进项目指令。一次性要求放在当前消息中。

## 管理历史与产物

- 侧栏展开项目即可查看最近会话，筛选器可区分普通、批量、对话和 Claw 会话。
- 项目详情显示会话数量，并提供新会话、导出和活动面板入口。
- 导出项目会包含项目文件、Vetta 会话历史和批量任务状态；文件锁会被排除。
- 「清空会话」删除历史但保留产物；「清空产物」删除输出文件但保留会话，两者语义不同。

<Callout type="warn" title="删除前先分清三种操作">
  「从列表移除」只改变 Vetta 列表；「清空会话」删除任务历史；「删除项目」会从磁盘永久删除整个目录。
</Callout>

## 推荐做法

1. 一个稳定目录对应一个项目。
2. 一个清晰目标对应一个会话。
3. 长期规则写入 `AGENTS.md`，本次验收写在任务消息里。
4. 需要比较方案时分叉，不在同一会话中来回覆盖目标。
5. 重要项目在破坏性操作前先使用项目导出或自己的版本控制。

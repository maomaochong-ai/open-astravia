## 平台和状态差异

- **远程连接**当前只在 Windows Desktop 设置中显示。
- **应用快照**和部分**权限管理**只在 macOS 显示。
- **账户**需要登录；开源 serv-less 构建不包含商业账户能力。
- **主题选择**可能受构建开关和已随应用打包的主题影响。
- 标有 **BETA** 或实验性质的入口，其字段和行为可能随版本变化。

## 修改设置的通用方法

1. 先在设置页完成修改并保存，不要直接编辑内部 JSON 作为第一选择。
2. 修改模型、MCP、IM、Webhook 或权限后执行对应的测试连接或最小任务。
3. 需要迁移或诊断时，先停止相关任务，再阅读[配置与数据路径](/reference/configuration-paths/)。
4. 只复制不含密钥的配置结构；Token、Cookie、OAuth 状态和 Webhook URL 不应进入项目或问题报告。

## 常见误区

| 现象 | 正确判断 |
| --- | --- |
| 系统终端的 Node/Python 正常 | 不代表 Vetta 内置运行时已就绪 |
| 输入了 API Key | 不代表该模型已能完成真实调用，需要单独验证 |
| 打开了插件权限 | 不代表插件代码处于安全沙箱，插件仍运行在 Desktop renderer realm |
| 创建了自动化 | 不代表错过的时间点会自动补跑 |
| 撤销了 IM 渠道 | 不代表第三方平台账号或本机所有状态都已删除 |

<Callout title="设置入口不是跨版本 API" type="info">
  设置名称、可见性和表单字段属于用户界面。脚本和集成应优先使用公开 SDK、RPC、CLI 或明确承诺的配置字段，不要依赖未公开的 DOM、内部路径或菜单顺序。
</Callout>

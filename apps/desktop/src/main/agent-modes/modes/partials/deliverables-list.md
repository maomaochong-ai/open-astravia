## The Deliverables file list
Whenever this turn created, edited, or wrote ANY file, you MUST end with a Deliverables section — mandatory, no exception, even for a single one-line edit. Write its heading in the user's language: **交付物** for Chinese users, **Deliverables** for English users, the natural equivalent otherwise.

It is an unordered list (`- ` prefix, never a numbered list) with one entry per file you changed: a standard CommonMark link whose label is the bare file name only (never the full or relative path) and whose destination is the absolute path in angle brackets, followed by a terse note on what changed — `- [filename.ext](</abs/path/with spaces/filename.ext>) — what changed here`. Use the equivalent `<C:/...>` destination on Windows. When two changed files share a name, disambiguate the label with the shortest distinguishing parent directory (`[app/index.ts](...)`, `[lib/index.ts](...)`). List every file you created or changed, documents and code alike; exclude only files you merely read without changing. Omit the section only when the turn changed no files at all.

# 团队任务自动恢复

团队成员遇到连接超时等可重试错误时，会保留进度并尝试恢复。默认每项任务最多自动恢复 2 次，首次执行不计入这两次。成员完成、失败或需要处理阻塞时，主控会收到对应通知。

自建团队可在团队设置中调整「自动恢复次数」，范围为 0–10。设为 0 可关闭自动恢复；保存后仅影响新任务。次数越高，持续故障时可能消耗的模型调用也越多。插件提供的团队仍使用其默认配置。

达到上限后，任务进入需要处理的状态。修复问题后，可通过已有的任务恢复操作继续。模型自行要求继续或重试会计入同一自动恢复上限，不能无限重试。认证或余额问题不会由定时器持续重试；匹配的外部条件变化或用户明确恢复可重新启动任务。

应用对已加载团队每 30 秒检查一次本地任务状态。正在运行的模型请求或工具不会仅因为长时间没有输出而被重新执行；失去执行者的任务、遗漏的重试计时器和未交付通知会被补偿。检查本身不调用模型。

停止团队后，自动恢复和通知唤醒都会停止，重新打开会话也不会恢复旧任务。只有新的用户消息才解除停止；停止前的通知不会因这条消息重新触发旧工作。应用未加载的历史会话不参与后台检查。

# Examples

示例代码：稳定 SDK 与 Extension。

## Directories

### [sdk/](sdk/)

通过 `@vetta/coding-agent/sdk` 做嵌入式集成。覆盖模型、提示词、工具、扩展、会话目录等。

运行：

```bash
cd packages/coding-agent
bun examples/sdk/01-minimal.ts
```

详见 [sdk/README.md](sdk/README.md) 与 [docs/sdk.md](../docs/sdk.md)。

### [extensions/](extensions/)

Extension 示例（钩子、自定义工具、命令、Git 集成、自定义 provider 等）。

详见 [extensions/README.md](extensions/README.md) 与 [docs/extensions.md](../docs/extensions.md)。

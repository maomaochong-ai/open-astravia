# Image quality checklist

Evaluate the actual rendered image against the workflow objective and intended surface.

## Must-pass checks

- Correct artifact, subject, required objects, and aspect ratio.
- Hard constraints and reference roles are respected.
- Identity, logo, label, product geometry, and required text are acceptable.
- No severe anatomy, object-merging, crop, perspective, or spatial errors.
- The image is usable at the target size and leaves required copy/safe space.

## Creative checks

- A clear focal hierarchy reads immediately.
- Composition supports the purpose rather than generic beauty.
- Light, color, material, and medium form one coherent direction.
- Background detail supports the subject without competing with it.
- The result is specific enough to distinguish from a default model output.

## Iteration discipline

Name the failed criterion and preserve the successful decisions. Fix prompt ambiguity before changing models. Replace a reference when its artifacts or contradiction are causal. Change model/mode only when the failure maps to a capability gap.

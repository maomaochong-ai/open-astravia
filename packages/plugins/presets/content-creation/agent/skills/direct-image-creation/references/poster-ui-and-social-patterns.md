# Poster, illustration, UI, and social patterns

## Posters and illustration

Choose a governing composition before style:

- time split: one location/perspective, two states with a controlled transition;
- figure/type poster: exact headline, figure overlap limit, strong color field;
- ornamental symmetry: central subject, mirrored botanical/graphic system, defined print process;
- technical/naturalist plate: specimen hierarchy, cross-section/detail, restrained labels;
- campaign collage: environment, action, detail, and message hierarchy.

Describe visual properties instead of stacking artist names. Define palette, line/edge treatment, shadow logic, texture/printing marks, border behavior, and negative space.

## UI mockups

Treat the interface as a plausible shipped state:

- device/viewport and platform conventions;
- screen purpose and user state;
- layout tracks, spacing, hierarchy, navigation, controls, and realistic data;
- exact visible copy;
- design-system behavior rather than decorative “futuristic UI” language.

For dashboards, require valid axes, labels, scales, units, and plausible values. Generated UI is a visual concept, not implementation truth.

## Social formats

- Story/reel cover: 9:16, immediate focal point, protected platform UI zones.
- Feed post: 1:1 or 4:5, thumbnail-readable hierarchy, at most two type levels.
- App-store asset: device accuracy, one feature claim, realistic screen, clean background.
- Thumbnail: identity/expression, opposing focal object, short exact headline, robust small-size contrast.
- Carousel: one master system with a distinct job per slide; do not repeat the same composition.

Use format-specific compositions rather than blind crops. State the no-text system zones and CTA/copy safe areas.

## Quality gate

Review at actual mobile thumbnail size. Check exact copy, contrast, hierarchy, safe zones, device geometry, UI plausibility, chart validity, brand consistency, and whether decorative elements compete with the message.

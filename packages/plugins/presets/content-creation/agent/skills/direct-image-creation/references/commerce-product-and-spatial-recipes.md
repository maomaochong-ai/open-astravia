# Commerce, product, and spatial recipes

## Amazon or ecommerce listing set

Required inputs: product authority image, category, verified features, target buyer, marketplace rules, and requested image slots.

Build assigned assets, not four generic product pictures:

1. Main image: isolated product, compliant background, complete silhouette, accurate color and geometry, no unsupported props or claims.
2. Lifestyle proof: credible user/context showing scale and use without obscuring the product.
3. Feature graphic: only verified features, one benefit per callout, readable hierarchy, no invented badges.
4. Material/detail proof: macro view of a real differentiator, connector, finish, seam, control, or texture.
5. Optional comparison/A+ modules: explicit comparison basis, structured copy, and distinct narrative job.

Generate independent assigned views in parallel only after the authority asset passes. Deliver in listing order and flag assets that still require exact-copy layout work.

## Multi-angle product set

Record product geometry, labels, materials, controls, seams, and orientation markers. Assign each view a camera contract: front, three-quarter, side/back, top, hero, and category-specific detail.

- Keep background, focal length family, product scale, light direction, and color treatment fixed.
- Change only camera/view role between branches.
- For footwear include sole when relevant; for electronics show ports/controls; for jewelry add macro material/facet proof.
- Do not call unrelated regenerated backs or sides a true 360-degree record. If exact unseen geometry matters, request real reference coverage or a 3D workflow.

## Giant product or scale-play still

Use a clean product authority and define an explicit scale cue: person, architecture, street furniture, or environment contact. Preserve package proportions and label placement. Add believable contact, occlusion, perspective, and shadow. Generate the still first; only hand it to video after the impossible scale reads clearly in one frame.

## Ingredient burst or product-motion keyframe

Define product center, ingredients and their semantic relation, trajectory, depth layers, background color, and frozen-action state. Keep label readability and avoid ingredient duplication/merging. The still must communicate the promised freshness/flavor without relying on later motion.

## Product glamour still

For jewelry or small premium goods, use a material-first shot plan: one hero silhouette plus one assigned macro detail. State surface, key light direction, edge/rim behavior, reflection control, focal plane, and contact. Reject impossible facets, floating contact, fake engravings, or changed settings/stones.

## Floor plan to spatial visualization

Treat the plan as structural authority, not loose inspiration.

1. Obtain dimensions, orientation, room labels, walls/openings, circulation, and immovable services when accuracy matters.
2. If generating a concept plan from text, label it illustrative and verify adjacency/circulation before continuing.
3. For an isometric/3D conversion, preserve wall/opening relationships and room adjacency. Change materials, furniture, light, and camera, not structure.
4. Review doors, windows, stairs, plumbing logic, furniture clearance, scale, and whether the render contradicts the plan.

Generated floor plans and renders are design concepts, not construction documents or code-compliance evidence.

## Existing-room redesign

Use the room photo as geometry authority. Write a two-part contract:

```text
Preserve: walls, openings, ceiling, fixed services, camera viewpoint, room scale.
Change: furniture, finishes, palette, lighting fixtures, decor, and named style elements.
```

Produce one main design, then an alternate only if it tests a named decision. Check window/door survival, circulation, plausible furniture scale, contact shadows, reflections, and whether the requested style is expressed through specific materials and forms.

## Empty-room furnishing

When no room image exists, create and approve the empty spatial shell first. The furnished pass references that shell and adds an explicit furniture program. This separates layout acceptance from styling and makes structural drift visible.

# Presentation visuals

This reference designs an image used inside a slide. It does not replace a presentation authoring tool or guarantee editable slide text.

## Slide discipline

- One slide communicates one idea.
- Use one focal hierarchy: claim, evidence, implication.
- Keep body copy short; if the visual needs paragraphs, typeset them outside the generated image.
- Reserve safe areas for editable titles, charts, or presenter overlays.
- Use one image language across the deck: photography, illustration, diagram, or restrained mixed system.

## Layout choices

- Hero: one dominant image/object and protected title area.
- Split 60/40 or 70/30: claim/evidence or text/visual.
- Comparison: matched columns with identical criteria.
- Process/timeline: explicit sequence and connectors.
- Data highlight: one hero number plus a small supporting chart.
- Bento: modular evidence, maximum visual hierarchy remains obvious.
- Asymmetric editorial: creative decks where controlled imbalance helps.

## Prompt contract

```text
Slide Job: <single idea and audience>
Visual Anchor: <subject/data/metaphor>
Layout: <tracks, proportions, safe areas>
Hierarchy: <first, second, third read>
Palette/Type Area: <colors and copy placement>
Constraints: <minimal baked-in text, legibility, no decorative clutter>
Format: 16:9 unless the actual deck differs
```

Validate the visual at projected size and thumbnail size. Check contrast, crop, consistency with neighboring slides, and whether the image strengthens the claim rather than simply making the slide decorative.

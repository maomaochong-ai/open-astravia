# Multi-panel and sequential images

Distinguish two outputs:

- Panel sheet: one generated image contains every cell.
- Sequential assets: separate images generated one at a time and later assembled.

Use separate assets when identity, detail, editability, or downstream animation matters. Use a panel sheet for pitches, contact sheets, fast overview, and layouts where one composition is the deliverable.

## Panel specification

Always state:

- exact grid dimensions and orientation;
- panel numbering and reading order;
- border/gap behavior;
- one distinct job and visual description per panel;
- shared identity, wardrobe/product, palette, light, and medium;
- which elements may change;
- caption/text rules and target size.

More panels mean less detail per panel. Keep 9-12 panel descriptions short and visually distinct. Never request “various angles” without assigning each angle to a cell.

## Common structures

- 2x2 identity/editorial grid: front, detail, low/high angle, profile.
- Three-panel campaign: hero, detail, action.
- 3x2 cinematic sequence: establish, power, detail, action, reaction, final state.
- 3x3 commercial board: hook through pack shot.
- Before/after split: identical camera and environment, one controlled state change.
- 3x4 storyboard poster: 12 ordered beats with minimal captions.
- Borderless mood mosaic: unified subject/style with no gaps.

## Sequential workflow

1. Define character/product and environment ledgers.
2. Define beat, function, composition, and end state for every image.
3. Generate one anchor frame and approve it.
4. Generate frames one at a time using the approved anchor.
5. Check continuity before proceeding.
6. Assemble only accepted frames.

For video keyframes, each panel must communicate a state change and handoff rather than just a pretty camera angle.

## Routing rules

- Use `$create-content-campaign` when the output is a coordinated set with an approval gate, not just one image.
- Use `$direct-video-creation` after an approved still becomes a motion anchor.
- Do not adopt provider names from a recipe. Inspect capabilities, then map the recipe's required behavior to an available mode.
- Preserve the recipe's task shape even when the exact model is unavailable: authority asset, candidate count, dependency order, gate, and fallback are more durable than model IDs.
- If a requested operation cannot be represented by current nodes, build the supported upstream artifacts and state the missing downstream production step.

# Treatment, script, and beats

## Director treatment

Define:

- core idea;
- emotional arc: opening -> turn -> ending;
- visual motif and anchor object;
- world, palette, material, and light rules;
- dominant camera relationship;
- rhythm and the location of the pause;
- sound texture and silence;
- ending image.

Translate named stylistic references into observable composition, light, texture, staging, and rhythm. Use at most one dominant reference per scene and avoid imitation as a substitute for direction.

## Beat spine

For each beat write:

`Function -> physical event -> pressure/change -> visible end state -> handoff`

Useful functions: hook, establish, reveal, power, pressure, detail, reaction, shift, impact, aftermath, exit. A beat without change or pressure is optional decoration.

## Script discipline

- Convert abstract emotion into body, object, environment, and sound.
- Give dialogue a visible action anchor and enough time for natural delivery.
- Maintain readable spatial geometry and screen direction.
- State what the viewer should notice first.
- End every stage on a visible state that can become a keyframe or edit point.

## Production handoff

Pass downstream: accepted brief, treatment, beat spine, continuity anchors, reference roles, hard constraints, candidate hypothesis, first proof to generate, and quality gate. Do not pass only a poetic paragraph.

# Recipe catalog

Choose the smallest recipe that covers the requested deliverables, then adapt it to inspected capabilities.

## Product launch system

Brief -> three concept hypotheses -> approved product hero -> detail/lifestyle stills -> motion proof -> hero film -> channel derivatives.

Protect product geometry, label/logo, materials, offer hierarchy, and brand palette. Validate the hero still before image-to-video.

## Cinematic product film

Brief -> visual language -> shot jobs -> keyframes -> motion proofs -> final shots -> ordered sequence manifest.

Typical shot jobs: establish world, reveal product, prove material/detail, demonstrate benefit, resolve on brand frame. One shot should not perform every job.

## Ad creative set

Brief -> hypothesis matrix -> one candidate per hypothesis -> evidence-based selection -> format variants.

Useful hypotheses include benefit, problem/solution, product beauty, demonstration, testimonial/social proof, and lifestyle identity. Keep offer and brand constraints fixed so the variable remains interpretable.

## Social content pack

Master direction -> feed image -> story/reel cover -> short motion hook -> banner/thumbnail -> delivery audit.

Compose each format for its native hierarchy. Do not treat every deliverable as a crop of the master.

## UGC-style ad

Brief -> credible creator/persona -> hook variants -> demonstration beats -> proof/result -> call to action -> vertical edit.

Keep performance natural, locations plausible, and camera language intentionally informal. Separate spoken copy, visible action, and generated audio requirements.

## Character story or photo pack

Character ledger -> neutral identity anchor -> approved look -> expressions/poses/environments -> keyframes -> optional motion shots.

Reject identity drift before multiplying assets. Change one continuity axis per branch.

## Storyboard to video

Story objective -> beat sheet -> shot list -> continuity ledger -> composition keyframes -> selected start/end frames -> timestamped shot generation -> ordered sequence manifest.

Prioritize staging, screen direction, and final-frame handoffs before polish.

## Brand or logo system

Strategy -> mark hypotheses -> selected logo authority -> palette/type/usage system -> application proofs -> publishing assets.

Keep logo exploration flat and isolated. Mockups and social outputs are descendants, not alternate logo authorities.

## Ecommerce listing pack

Product authority -> main image -> lifestyle proof -> verified feature graphic -> material/detail views -> optional campaign hero.

Assign each image a listing job. Parallelize views only after geometry, label, color, and material fidelity pass.

## Long-form distribution pack

Source/transcript -> candidate spans -> score and dedupe -> selected time ranges and crop specifications -> covers/captions -> delivery manifest.

If transcription, highlight ranking, face tracking, or final render is outside inspected capabilities, produce the supported plan and state the external step.

## Spatial or interface concept set

Source/requirements -> structural or product-state authority -> main concept -> named alternate -> desktop/mobile or view variants -> feasibility and fidelity audit.

Treat generated plans, interiors, and UI as concepts until the relevant professional or implementation workflow verifies them.

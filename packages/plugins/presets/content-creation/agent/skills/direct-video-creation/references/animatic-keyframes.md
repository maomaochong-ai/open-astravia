# Animatic keyframes

An animatic keyframe is a still that carries a story beat without motion. Use `$direct-image-creation` to generate it, then return here to animate approved frames.

## Keyframe card

Define:

- panel ID, time, and hold duration;
- function and one-sentence beat;
- framing/lens and one focal anchor;
- foreground, action plane, and background jobs;
- implied camera move;
- emotion expressed through body/object/environment;
- motion rendered as a still cue;
- light/palette and texture;
- sound under the held frame;
- visible state and production/continuity note.

The panel must carry one beat, one function, one emotion, and one implied motion. Otherwise drop it.

## Render motion in a still

Use one or more observable cues:

- sharp subject against directional background smear;
- one moving element in partial blur while the anchor stays crisp;
- full-frame streak with one surviving readable form;
- posture/trajectory that can resolve only in one direction;
- sharp detail against a dissolved field;
- deliberate zero-blur stillness before impact.

Do not write “dynamic.” Name what is sharp, what blurs, the direction, and the physical consequence.

## Emotion without faces

Redistribute face functions:

- decision -> hand/foot/body mid-action;
- pressure -> object crossing a threshold;
- rivalry/gaze -> spatial geometry;
- cost -> material deformation, residue, or release.

An object becomes dramatic only when its state changes. A static lever is decoration; a lever at the committed end position is a decision.

## Loaded frame

Use one focal point and three depth layers:

- foreground frames, obstructs, or locates the viewer;
- midground carries the act;
- background carries stakes, context, or handoff.

Every object must indicate state, advance action, or bridge to the next panel. Remove decorative clutter.

## Density

Quiet ritual or aftermath gets one held panel. Rising pressure gets progressively shorter panels. Impact gets a brief cluster. Never place two dense clusters together without a held breath between them.

## Handoff to video

Use an approved keyframe as identity/composition/start-state authority. The video prompt describes motion, camera, environmental response, audio intent, and final state without re-describing the still. Confirm that the selected mode accepts the reference slot.

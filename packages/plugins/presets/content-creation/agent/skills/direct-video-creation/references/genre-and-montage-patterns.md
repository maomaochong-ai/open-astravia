# Genre and montage patterns

Choose one structure, then fill it with task-specific physical detail.

## Montage structures

- Escalation: wide -> medium -> close -> detail -> reaction -> impact.
- Anxiety: face/body -> object -> hand -> tighter object -> sound cue -> stillness.
- Discovery: POV -> search geometry -> reaching action -> hidden object -> focus shift -> reaction.
- Catastrophe: anticipation -> instability -> recognition -> fall/failure -> impact -> silence -> residue.
- Product drama: lifestyle friction -> reveal -> material proof -> use -> benefit consequence -> hero/end state.
- Rhythmic loop: gesture -> new angle -> transformation -> repeated gesture -> release.

Every adjacent shot should differ in function, framing, or state. Repetition is useful only when escalation changes its meaning.

## Genre modules

- Psychological drama: locked frames, negative space, reflections, quiet environmental pressure, long reaction.
- Action: establish geography, maintain threat/escape directions, alternate wide proof and impact detail.
- Commercial: clear product truth, tactile macro, use consequence, readable final product state.
- Fashion: silhouette, fabric movement, repeated form, controlled palette, confident stillness.
- Music video: motif, beat-driven repetition, graphic match, transformation, loop/release.
- UGC/social: vertical staging, credible practical light, direct behavior, fast hook, natural imperfection.
- Product film: form reveal, material proof, functional movement, human benefit, brand frame.
- Dialogue scene: stable character labels, shot/reverse-shot geometry, visible anchors, speech timing, reaction space.

## Multi-clip structure

Repeat identity, wardrobe/product, location, visual system, camera grammar, light source/direction, palette, and continuity invariants in every independent generation. Match the prior final state at the next opening. Return an ordered sequence manifest rather than asking one unsupported node to create a full film.

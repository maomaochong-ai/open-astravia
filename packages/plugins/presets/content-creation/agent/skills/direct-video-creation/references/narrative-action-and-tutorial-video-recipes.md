# Narrative, action, and tutorial video recipes

## High-cut-density fight or action scene

Action quality depends on geography, identity, and edit rhythm before surface polish.

1. Build a character authority sheet with asymmetric identifiers when useful.
2. Build an environment plate that exposes entrances, obstacles, cover, height, and travel paths.
3. Convert the action into beats: threat, defense, reversal, impact, recovery, and resolve.
4. Create a storyboard/contact sheet or individual keyframes. Assign shot size, camera axis/move, screen direction, and rhythm to every panel. Alternate geography-proving wides with impact close views.
5. Approve identity, spatial logic, and cut density before video.
6. If a model can read a composite storyboard reference, use it as choreography guidance while retaining clean identity/environment authorities when slots allow. Otherwise render shots independently and edit on the timeline.
7. Proof the riskiest impact or transition first. On failure, retry the video with fewer beats before rebuilding approved upstream art.

Longer fights should use consecutive storyboard blocks with an explicit end-state/start-state handoff.

## Character story

1. Establish one character reference and continuity ledger.
2. Write a simple arc and assign each scene a distinct narrative change.
3. Generate scene keyframes from the same authority, varying only the required environment/action.
4. Approve the ordered still sequence before animation.
5. Animate one coherent event per scene and assemble clips on the timeline.

Repeat the minimal identity block in every independent generation. Do not rely on chat memory or let each scene redesign the character.

## Storyboard-driven cooking or process tutorial

Use dual authority when the mode supports it:

- clean subject/product image controls identity or object fidelity;
- a production board controls environment and ordered actions.

Build the board with a small character/object reference zone, an environment plate, and numbered action panels. Match panel count to duration; a short clip cannot carry a long procedure. Approve likeness, environment, and process order before the expensive video pass.

For video, assign one action per timed beat, use close views for hand/process evidence and medium/wide views for orientation, state continuity of outfit/tools/workspace, and specify relevant ambience/effects. End on the completed result.

If a single continuous generation cannot represent the process reliably, split it into assigned step clips and edit them in order.

## Music video

1. Define musical structure, motif, subject/character authority, visual progression, and number of scenes.
2. Produce scene keyframes and a music/audio plan in parallel only after the treatment is stable.
3. Give each clip one motion idea and one relationship to rhythm: downbeat cut, sustained phrase, repetition, release, or transition.
4. Repeat visual anchors across scenes and assemble clips to the planned beat map.

Do not claim beat synchronization unless the selected mode accepts the audio reference or the timeline/edit stage actually aligns to it.

## Storyboard-only request

Stop after ordered keyframes and captions. Report continuity anchors and which frames can serve as motion start/end references. Do not add video, audio, or upscale work without authorization.

## Narrative quality gate

Check that every scene visibly changes state, every shot has a job, screen direction is intentional, references have explicit roles, the action count matches duration, and each final frame supports the next cut or a clean ending.

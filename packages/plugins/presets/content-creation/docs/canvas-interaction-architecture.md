# 画布交互架构

## 参考结论

本轮只依据 Open-AI Canvas 与 Loomic 的源代码行为分析，不依据项目截图。两者最值得吸收的共同点不是具体视觉样式，而是让操作贴近内容对象：创建后立即选中，参数面板锚定节点，媒体本身占据节点主体，常用操作出现在选区附近，画布空白处和连线末端都可以直接创建内容。

Open-AI Canvas 对复杂节点图更成熟的部分包括多选编排、连接命中区、拖拽参考线、任务状态与错误反馈；Loomic 更值得参考的是生成占位对象的视口居中、比例变化时保持中心、轻量媒体加载，以及 AI 工具和普通画布工具处于同一操作层级。

## 当前实现边界

- React Flow 继续负责视口、选择、框选、多选拖拽、连线和缩放，不重复实现画布内核。
- `ContentProjectCommand` 是所有持久化修改的唯一入口。React 组件不直接修改项目文档。
- 项目文档是持久化节点和连接的唯一权威状态；React Flow 本地状态只承载拖拽、缩放等尚未提交的瞬时交互。
- React Flow 使用 `defaultNodes/defaultEdges` 管理拖拽、测量和选中等瞬时状态，不接收受控的 `nodes/edges` 属性。只有项目版本或模型语义变化时，工作区才通过实例 API 单向同步一次持久化快照；选区变化不会触发整图回写，避免与内部 store 和 `ResizeObserver` 形成反馈环。
- 节点锁定属于领域状态；锁定节点不可移动或缩放，布局命令会跳过锁定节点。
- 单选时显示节点标题工具条和节点下方参数面板；多选时替换为选区工具条，不同时打开多个节点面板。
- 多选工具条提供六向对齐和横向、纵向、网格排列，结果转换为一批 `node.move` 命令并按一次修订保存。
- 拖拽参考线比较节点的左、中、右及上、中、下锚点，阈值按当前缩放比例换算，保证不同缩放下手感一致。
- 右键节点提供复制、锁定和删除；右键连接提供删除；双击或右键空白画布打开创建菜单。
- 所有画布菜单在打开时根据画布可见区域进行边界约束，避免被活动面板边缘裁切。
- 连线端口使用较大的透明命中区域和较小的视觉圆点；边线使用独立的宽交互路径，不以视觉线宽换取可点击性。
- 生成节点读取最近一次 `GenerationJob`，在节点内容层展示进度、失败状态，并在节点参数面板提供重试入口。

## 没有直接照搬的部分

- 不引入 Excalidraw，也不把节点图改成自由绘图模型；以后需要标注、形状或 Frame 时，应作为非执行画布对象扩展。
- 不在生成成功后把生成器替换为不可重放的媒体对象；节点保留参数、模型和上游连接，产物通过 `assetId` 引用。
- 不加入常驻属性侧栏或节点属性浮窗；完整参数仍锚定当前节点。
- 不新增硬编码键盘监听。当前插件快捷键 SDK 只提供作用域注册，不提供插件命令到用户可配置按键的映射，因此画布先提供显式操作，并关闭 React Flow 内置删除键。后续应在宿主开放插件可配置命令映射后接入。

## 扩展点

后续画布能力继续沿现有边界扩展：新节点通过定义注册表增加；新模型通过 Provider/Model 能力注册表增加；新布局算法只输出节点位置；可恢复任务、取消和版本历史在 GenerationJob 与工作区命令层实现，不向节点组件塞入供应商或存储逻辑。

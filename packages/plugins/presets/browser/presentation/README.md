## 适合什么任务

Browser Use 面向必须在真实网页里完成的工作，例如登录后台、翻页查数据、填写表单、切换筛选条件，或把多个页面的结果整理到一起。仅需要公开资料摘要时，优先使用网页搜索；需要“进入页面并把事情办完”时再使用浏览器操作。

## 使用方式

直接在对话中说明目标、网址和不能越过的边界。遇到登录、验证码或二次验证时，Agent 会把可见浏览器窗口交给你处理，完成后继续任务。涉及发布、付款、删除或最终提交时，建议明确要求停在确认前。

首次使用需要安装插件锁定的 `agent-browser` 运行时。如果系统没有可复用的 Chrome，还会安装 Chrome for Testing。运行时由 Vetta 单独管理，不会覆盖机器上的全局安装。

## 会话与隐私

每个 Agent 对话使用独立的浏览器 session，不会接管其它对话的活动页面。需要长期保存登录态时使用稳定 profile；同一任务操作多个账号时使用不同的账号键。不要把邮箱、密码、Cookie 或 token 写进 profile 名称、提示词或日志。

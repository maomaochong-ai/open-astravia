---
title: 配置 IM 渠道
description: 将飞书或微信连接到 Vetta Claw，并验证消息收发。
---

当前支持飞书和微信 iLink。一次只启用一个活动传输渠道；切换渠道前先确认旧渠道中的任务已经结束。

## 配置飞书

1. 在飞书开放平台创建企业自建应用并启用机器人能力。
2. 开启长连接事件订阅，订阅 `im.message.receive_v1`。
3. 为应用授予接收和发送消息所需权限，并发布应用版本。
4. 在“设置 → Claw”填写 App ID 与 App Secret，执行连接测试后保存。
5. 向机器人发送消息，检查 Vetta 状态和日志。

密钥只应填写在本机配置界面，不要写入项目文件或问题报告。若收不到消息，依次检查应用是否已发布、事件订阅、权限、机器人可见范围和 Vetta 是否仍在运行。

## 绑定微信

在“设置 → Claw”选择微信绑定，使用微信扫描二维码并确认。绑定完成后发送一条测试消息；需要更换账号时先解除现有绑定，再重新扫码。

二维码过期时刷新后重试。绑定成功但无回复时，检查 Claw 总开关、当前活动渠道、网络和运行日志。

完成渠道配置后，阅读 [Vetta Claw](/product/claw/)了解会话命令、记忆和安全边界。

---

Vetta 桌面端将 Agent、项目上下文和本地工具整合在一个工作空间中。

## 对话与项目

会话记录模型回复、工具调用和任务结果。项目用于组织会话及其工作目录，让同一目标下的上下文保持连续。

## 批量任务

批量任务使用一个任务描述处理多个目标目录，适合重复检查、迁移或内容处理。执行器支持并发度控制、暂停、重试和重新开始。

## 自动化

自动化项目通过计划规则触发任务，适合周期性检查和固定流程。自动执行前应确保任务范围、权限和失败处理方式足够明确。

## 工作流

工作流通过有向图组织多个 Agent 或处理步骤，用于表达有依赖关系的复杂过程。每个节点应保持单一职责，并清楚定义输入与输出。

## 扩展能力

Vetta 可以通过技能、插件、MCP 和主题扩展能力。插件能够接入界面和宿主能力，相关安全边界见[插件概览](/plugins/overview/)。

---
title: 使用知识库
description: 导入本地资料、生成可检索知识并处理失败记录。
---

知识库用于保存需要长期复用的资料。导入负责组织原始文件，后台处理负责把内容整理为 Agent 更容易检索的知识；两者是不同阶段。

## 创建并导入

1. 打开侧栏“知识库”，新建知识库或进入默认知识库。
2. 选择文件或文件夹，也可以把资料拖入页面。
3. 在文件列表确认导入结果和处理状态。
4. 回到会话，明确要求 Agent 使用对应知识库回答一个可核对的问题。

优先导入结构清晰、文本可提取的资料。扫描图片型 PDF 可能需要先做 OCR；超大文件应按主题拆分，避免一次处理过多无关内容。

## 配置后台处理

打开“设置 → 知识库”，选择处理模型与推理级别，先执行连接测试，再设置处理间隔和并发数。并发越高，处理越快，但会增加模型配额、速率限制和本机负载。

可以使用“立即处理”主动开始，或对失败记录执行重试。若持续失败，检查模型配置、供应商限额、文件是否可读取以及格式是否包含可提取文本。

“清空 Wiki”会移除已经生成的知识结果，需要重新处理才能恢复检索能力；操作前确认原始文件仍然保留且可重新处理。

Vetta Claw 是随桌面客户端运行的长期助手。它通过默认会话连接桌面与已绑定的 IM 渠道，适合随时继续任务，而不是替代项目内精确、可审计的工作流程。

## 开始使用

1. 打开“设置 → Claw”，启用 Vetta Claw。
2. 在同一页面配置飞书或微信，详细步骤见 [IM 渠道](/product/im/)。
3. 确认状态为运行中，保持桌面客户端开启。
4. 从已绑定渠道发送一个低风险请求，并在桌面默认会话中核对结果。

Claw 会在会话切换时整理值得长期保留的信息，但不要把它当作唯一事实来源。关键约束仍应保存在项目文档、知识库或明确的任务说明中。

## 会话命令

- `/new`：结束当前上下文并开始新会话；切换前会尽力保存适合长期记忆的事实。
- `/whoami`：查看当前渠道身份和诊断信息。
- `/help`：查看当前支持的命令。

## 使用边界

IM 请求使用默认会话的工作目录，不在渠道内切换项目。涉及批量修改、敏感权限或复杂验收时，回到桌面客户端确认工作目录、执行模式和工具调用。完全退出 Vetta 会同时停止 Claw 和消息接收。

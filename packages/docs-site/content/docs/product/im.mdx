---
title: 配置 IM 渠道
description: 在设置 → Claw 中配置飞书或微信，并切换活动传输渠道。
---

消息渠道配置位于 **设置 → Claw** 的 **消息渠道** 区域。当前支持 **飞书** 与 **微信（iLink）**。同一时间只有一个 **活动渠道**；切换前请确认旧渠道上的任务已结束。

完成渠道配置后，阅读 [Vetta Claw](/product/claw/) 了解总开关、对话模型与会话命令。

## 配置飞书

桌面端表单主要填写 **App ID** 与 **App Secret**，可在对话框内 **测试连接** 后保存。飞书开放平台侧需自行完成应用创建与发布（细节以飞书开放平台当前文档为准），典型要求包括：

1. 创建企业自建应用，并启用 **机器人** 能力。
2. 事件订阅使用 **长连接**，订阅 `im.message.receive_v1`（接收消息）。
3. 授予收发消息所需权限，并发布应用版本。
4. 在 Vetta **设置 → Claw** 填写 App ID / App Secret，测试连接后保存，并将活动渠道切到飞书。
5. 向机器人发起私聊发送消息，在 Vetta 状态与日志中核对。

密钥只填在本机配置界面。收不到消息时依次检查：应用是否已发布、事件订阅、权限、机器人可见范围、Claw 总开关、活动渠道是否为飞书、Vetta 是否仍在运行。

## 绑定微信

1. 在 **设置 → Claw** 打开微信卡片上的 **绑定** / **管理**。
2. 使用微信扫描二维码并确认（iLink 机器人绑定流程）。
3. 绑定成功后，将活动渠道切到微信并发送测试消息。
4. 更换账号时先 **解除绑定**，再重新扫码。

二维码过期时刷新重试。绑定成功但无回复时，检查 Claw 总开关、活动渠道、网络、对话模型与实时日志。

## 状态与日志

同一设置页提供：

- 传输状态徽章
- sidecar 进程信息与最近错误
- **查看日志**（实时日志抽屉）
- **重启**（在已启用时）

若存在旧版 IM 数据，可能出现迁移横幅，可按提示导入或跳过。

---
title: 管理应用环境
description: 检查和修复 Vetta 内置的 Node.js、Python 与包镜像配置。
---

“设置 → 应用环境”管理 Vetta 随应用提供的 Node.js 和 Python。它们会注入 Vetta 启动的 Agent 与命令进程，不会修改系统终端、Shell 配置或全局运行时。

## 检查运行时

页面会显示内置 Node.js、Python 及 npm、pip 镜像地址。首次使用代码工具，或升级应用后运行时不可用时，点击“重新获取”修复当前应用固定的版本。

修复完成后，在 Vetta 会话中让 Agent 执行：

```bash
node --version
python --version
```

两个命令都应返回版本号。系统终端中的版本可以不同，这不代表 Vetta 配置失败。

## 安装依赖

Agent 运行 `npm`、`bun` 或 `pip` 时会使用页面显示的镜像配置。需要访问其他源时，应在具体项目或命令中显式配置，并确认组织的网络与安全策略允许访问。

内置环境不包含完整的本机编译工具链。只有源码分发、需要 C/C++ 或平台 SDK 编译的 Python/Node 原生依赖可能安装失败；这类项目应使用已经准备好的系统开发环境或预编译包。

“重新获取”只修复当前 Vetta 版本配套的运行时，不会将其升级到应用尚未支持的新版本。

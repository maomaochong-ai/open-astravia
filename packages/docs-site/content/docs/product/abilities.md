“能力”页面是 Vetta 的扩展入口。选择能力类型时，先从目标出发：技能提供任务指令，场景提供预设工作方式，MCP 连接外部工具，插件扩展桌面与 Agent，组合包一次组织多项能力。

## 从市场安装

1. 打开侧栏“能力”，浏览或搜索目标能力。
2. 打开详情，检查来源、版本、说明和所需权限。
3. 选择安装；组合包可以只选需要的成员。
4. 若 MCP 要求凭据，按提示完成配置；插件安装时逐项确认权限。
5. 安装后确认状态为启用，再回到会话验证能力是否出现。

## 导入本地能力

通过页面的导入菜单可导入技能归档或插件归档。插件 ZIP 的根目录必须包含 `plugin.json` 和构建产物；技能归档应保留自身目录结构与入口说明。只导入可信来源的文件。

## 管理与排错

禁用会保留安装内容但停止使用；卸载会移除本地安装。升级或重装后如果能力没有出现，先确认它已启用，再检查是否缺少凭据、权限或宿主版本要求。

需要开发扩展时，阅读[插件开发](/plugins/overview/)；只是连接一个工具服务时，阅读 [MCP 连接器](/product/mcp/)。

侧栏 **自动化**。调度在桌面客户端本地完成：任务按本机时间触发。**完全退出 Vetta 后不会继续触发**，需要保持应用运行。

## 推荐模板

页面提供推荐任务模板（可一键使用并再编辑），例如：

- 每日晨间简报（工作日示例文案）
- 每日工作总结
- 每周复盘

模板内的提示词默认要求用中文输出，且 **不要修改文件**（以模板正文为准）。

## 创建任务

点击 **新建任务**，主要字段：

| 字段 | 说明 |
| --- | --- |
| 任务名称 | 列表显示名 |
| 提示词 | 完整任务说明；可用 `/` 唤出技能 / 场景 |
| 工作目录 | 可选「对话」或已有项目目录 |
| 模型 | 执行所用模型 |
| 计划 | **单次** / **每天** / **间隔**（每隔 N 小时或按天换算的间隔） |
| 沙盒 | 跟随默认 / 完全访问 / 使用沙盒 |
| 启用 | 保存后是否处于可触发状态 |

<Steps>
  <Step>
    ### 填写提示与目录

    无人值守执行时，提示中写清输入来源、输出位置、失败条件与是否允许改文件。
  </Step>
  <Step>
    ### 选择计划

    确认描述中的下次执行时间符合预期。计划依赖操作系统当前时区；睡眠或关机可能错过触发。
  </Step>
  <Step>
    ### 保存并试跑

    使用 **立即执行** 验证结果，再保持启用状态等待调度。
  </Step>
</Steps>

## 查看结果

任务卡片显示启用 / 停用、最近运行结果等。打开详情可查看 **执行历史**（成功 / 失败 / 执行中 / 已中止）及对应会话。可 **暂停 / 启用 / 编辑 / 删除**。

项目维度的自动化概览也会出现在活动面板相关标签中。

需要对多个目录并发跑同一提示时使用 [批量任务](/product/batch-tasks/)。

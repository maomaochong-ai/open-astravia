---
title: 配置模型
description: 添加模型供应商、登记模型能力并选择默认模型。
---

模型配置决定普通会话、知识库处理、批量任务和自动化可以使用哪些模型。

## 添加预设供应商

1. 打开“设置 → 模型配置”。
2. 选择供应商，填写 API Key 或完成对应授权。
3. 使用“获取模型”读取供应商模型列表，或手动添加模型。
4. 保存后选择一个模型设为默认。

预设覆盖 OpenAI、Anthropic、Google、OpenRouter、Azure OpenAI、AWS Bedrock 等供应商。授权方式和必要字段会随供应商变化，以配置界面为准。

## 添加兼容供应商

没有预设时选择自定义供应商，至少填写名称、Base URL、API Key 和 API 协议。只有服务端要求时才增加自定义请求头或调整认证头。

手动登记模型时，模型 ID 必须与供应商接口一致。根据实际能力标记文本或图片输入、推理能力、上下文窗口和最大输出；错误声明会让客户端发送供应商不支持的参数。

## 验证配置

新建会话并显式选择该模型，发送一个短请求。若配置用于知识库，再到“设置 → 知识库”执行连接测试。常见失败来自 Base URL 多写或少写 API 路径、模型 ID 不存在、账户无权限或代理拦截。

配置保存在 `~/.vetta/agent/models.json`。不要把包含密钥的文件提交到仓库或发到问题报告中。

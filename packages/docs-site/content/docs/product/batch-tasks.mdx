---
title: 运行批量任务
description: 创建批量项目，用同一提示并发处理多个文件夹并校验产物。
---

入口：侧栏 **更多 → 批量任务**（路由 `/batch-tasks`）。适合对多个目录执行同一种相对独立的操作（检查、迁移、整理等）。子任务之间需要严格依赖或共享中间状态时，改用普通会话分阶段执行。

## 创建批量项目

点击 **新建项目**，填写：

| 字段 | 说明 |
| --- | --- |
| 项目名称 | 列表中显示的名称 |
| 提示词 | 任务说明；可用 `/` 唤出技能 / 场景 |
| 模型 | 子任务使用的模型 |
| 文件夹列表 | 每个文件夹对应一个子任务；可用选择器添加，或文本粘贴路径（每行一个，便于 Linux 多选不稳时） |
| 并发数 | 同时运行的子任务数 |
| 超时（分钟） | 子任务单次运行的硬超时；暂停后恢复会重新计时 |
| 沙盒状态 | 跟随全局默认 / 完全访问 / 使用沙盒 |
| 启用消息推送 | 可选；子任务完成与项目全部完成时向已配置 Webhook 推送（见 [消息推送](/product/webhook/)） |
| 产物校验 | 可选；每行一个文件名或 glob，**子任务目录顶层**须全部匹配才算成功 |

提示词应写清输入范围、允许修改的内容、禁止操作和完成标准。每个子任务应可独立重复执行，避免依赖「上一个文件夹已完成」的隐含状态。

## 先小规模验证

第一次只选一两个代表性文件夹，并发设为 1。确认提示词、权限与产物规则正确后，再扩大目标与并发。

## 运行与恢复

列表展示总数、运行中、已完成、失败等统计。常见操作：

- **开始**：按并发执行未执行 / 已暂停等目标任务（有确认框）。
- **停止**：中断运行中任务，并将除已完成外的任务清空会话与产物后重置为未执行（有确认框，不可撤回）。
- **重置失败**：清空失败任务的会话与产物；队列仍活跃时会加入队尾。
- 单任务：**执行 / 继续 / 重试 / 重新运行 / 删除**，以及 **跳转到会话**。

活动面板中的 **执行进度** 可对照批次状态。

批量任务不会按时钟自动触发。需要周期执行请用 [自动化](/product/automation/)。

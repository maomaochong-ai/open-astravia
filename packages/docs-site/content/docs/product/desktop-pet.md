---
title: 使用桌宠 Vetta Vivi
description: 启用桌宠、调整显示方式并处理遮挡或尺寸问题。
---

Vetta Vivi 是独立的透明桌面窗口，可以展示状态气泡和动作反馈。它不是 Agent 的另一个会话，重要任务仍在主窗口中确认。

## 启用与配置

1. 打开“设置 → Vetta Vivi”。
2. 启用桌宠并确认窗口出现在桌面。
3. 按需要开启置顶，并选择气泡样式。
4. 在主窗口触发一次会显示反馈的操作，确认气泡能够正常出现。

按住桌宠可拖动窗口；鼠标滚轮可调整当前动作的显示尺寸。桌宠图像之外的透明区域会尽量让鼠标事件穿透，减少对其他应用的干扰。

## 常见问题

- 桌宠挡住工作内容：关闭置顶，或拖到屏幕边缘。
- 桌宠太大或太小：将指针放在桌宠图像上滚动；不同动作可能保留各自尺寸。
- 启用后没有出现：先关闭再开启显示，检查是否在其他显示器或屏幕边缘，并确认 Vetta 主进程仍在运行。
- 气泡没有显示：确认气泡样式有效，并从主窗口触发一次新的状态消息。

调试边框属于开发诊断能力，不建议日常开启。当前公开设置主要覆盖显示、置顶和气泡样式，装饰内容不作为稳定配置接口。

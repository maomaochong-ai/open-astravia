## 按目标查找

- 要给 Agent 增加外部工具：阅读 [MCP 连接器](/product/mcp/) 或 [能力市场](/product/abilities/)。
- 要重复处理多个目录：阅读[批量任务](/product/batch-tasks/)。
- 要定时运行任务：阅读[自动化](/product/automation/)。
- 要在飞书或微信中使用：先配置 [IM 渠道](/product/im/)，再阅读 [Vetta Claw](/product/claw/)。
- 要扩展桌面界面或 Agent：从[插件开发概览](/plugins/overview/)开始。

## 创建会话

从项目侧边栏创建普通项目或会话。如果任务需要读取本地文件，请先选择对应工作目录，使 Agent 能在明确边界内获得上下文。

## 编写任务

一个可执行的任务应包含：

- 目标：最终希望得到什么结果。
- 范围：允许读取或修改哪些文件。
- 约束：技术栈、兼容性、禁止操作等要求。
- 验证：如何判断任务已经完成。

例如：

```text
检查当前项目的登录失败问题。只修改认证模块，补充回归测试，并运行该模块的类型检查和测试。
```

## 检查执行过程

Vetta 会在会话中展示模型回复、工具调用和阶段性结果。涉及文件修改、命令执行或外部系统的操作时，应核对目标和影响范围后再授权。

任务结束后至少检查：

1. 结果是否满足最初目标。
2. 修改是否限制在约定范围内。
3. 验证命令是否真实执行并通过。
4. 是否存在尚未处理的风险或人工步骤。

## 创建会话

在侧栏使用 **新建项目** / **打开项目** / **导入项目**，或进入默认 **对话** 工作区。

- 需要读写本地文件时，先选对 **工作目录（项目 cwd）**，Agent 在该边界内获得上下文。
- 会话列表在项目下方展开；批量任务、对话、Claw 等类型可在筛选中区分。

新建会话页可选择模型，并开始第一条消息。

## 编写任务

可执行的任务应尽量写清：

| 要素 | 说明 |
| --- | --- |
| 目标 | 最终希望得到什么结果 |
| 范围 | 允许读取或修改哪些路径 |
| 约束 | 技术栈、兼容性、禁止操作 |
| 验证 | 如何判断完成（测试、命令、产物） |

示例：

```text
检查当前项目的登录失败问题。只修改认证模块，补充回归测试，并运行该模块的类型检查和测试。
```

输入框支持：

- 选择 **模型**
- 选择 **执行模式**：**完全访问** 或 **沙盒受限**（沙盒在当前平台不可用时会提示原因）
- 使用 `/` 唤出技能 / 场景
- 附加图片等上下文（以界面能力为准）

## 执行过程中的确认

Agent 会展示回复、工具调用与阶段性结果。涉及敏感或高影响操作时，应用会弹出 **操作确认**（确认执行 / 拒绝）。应核对目标与影响范围后再授权。

在 **设置 → 通用设置** 中可配置 **默认沙盒状态**（新建会话未单独设置时使用，不改变已打开会话）。

## 检查结果

任务结束后至少核对：

<Steps>
  <Step>
    ### 结果是否达标

    回复与改动是否满足最初目标。
  </Step>
  <Step>
    ### 范围是否可控

    修改是否仍在约定文件与目录内。
  </Step>
  <Step>
    ### 验证是否真实执行

    约定的测试或命令是否真正跑过并通过。
  </Step>
  <Step>
    ### 是否有后续风险

    是否仍有未处理步骤、失败工具调用或需人工收尾的内容。
  </Step>
</Steps>

右侧 **活动面板**（视会话与功能启用情况）可能显示文件、待办、工具调用、后台任务等，便于对照过程。

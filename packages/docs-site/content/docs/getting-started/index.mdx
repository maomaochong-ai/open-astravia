## 准备工作

开始前请准备：

- 一台支持 Vetta 桌面客户端的计算机。
- 可用的 Vetta 账号。
- 至少一个可用的模型服务。具体可用范围由你的账号和组织配置决定。

## 安装与登录

1. 从 Vetta 官网下载适合当前操作系统和处理器架构的安装包。
2. 完成安装并启动 Vetta。
3. 登录账号；企业用户应使用组织管理员提供的登录方式。

## 配置模型

打开“设置”，进入模型与服务商配置区域。选择组织提供的模型，或按服务商要求填写自己的访问凭据。

<Callout title="警告" type="warn">
  访问密钥属于敏感信息。只应在 Vetta 的凭据配置界面中填写，不要把密钥写入提示词、项目文件或插件配置。
</Callout>

配置完成后，继续[运行第一个任务](/getting-started/first-task/)。

## 准备工作

- 一台支持 Vetta 桌面客户端的计算机（Windows / macOS / Linux，以实际发布包为准）。
- 可用的 Vetta 账号（桌面端通过浏览器 **授权登录** 完成身份认证）。
- 至少一个可用的模型服务：组织提供的远程模型，或你在「设置 → 模型配置」中自行添加的服务商与密钥。

## 安装与首次启动

<Steps>
  <Step>
    ### 下载并安装

    从 Vetta 官网下载适合当前操作系统和处理器架构的安装包，完成安装后启动 Vetta。
  </Step>
  <Step>
    ### 完成首次引导

    首次启动会进入引导流程，主要包括：

    1. **语言与外观**：选择界面语言（跟随系统 / 中文 / English）和外观偏好。
    2. **系统权限**（仅 macOS）：按提示完成应用所需权限。
    3. **登录**（未登录时）：点击 **授权登录**，在浏览器完成 OAuth 后返回应用。
    4. **欢迎页**：引导结束进入主界面。

    之后可在「设置 → 通用设置」中通过 **启动 App 引导** 重新打开该流程。
  </Step>
  <Step>
    ### 确认登录状态

    侧栏账户区域应显示已登录。企业用户使用组织提供的登录方式；授权链接失效时，在登录弹层中重新授权。
  </Step>
</Steps>

## 配置模型

打开 **设置 → 模型配置**（侧栏也可进入模型相关入口）：

1. 在 **预设服务商** 中选择已支持的服务商（如 Claude、OpenAI、DeepSeek、Z.ai (GLM)、Kimi、Grok、Qwen、Gemini 等），填写 API Key。
2. 使用 **从接口拉取** 获取模型列表并勾选添加，或手动 **添加模型**。
3. 将常用模型 **设为默认模型**。
4. 可选：调整全局 **思考** 档位（关闭 / 极低 / 低 / 中 / 高 / 极高）；模型不支持时会自动降级。

没有预设时，使用 **添加服务商** 配置自定义名称、API 类型、Base URL 与 API Key。

<Callout title="密钥安全" type="warn">
  访问密钥只应填写在凭据配置界面。支持 `sk-...`、`env:MY_API_KEY` 等形式。不要把密钥写入提示词、项目文件或问题报告。配置落在本机 `~/.vetta/agent/models.json`。
</Callout>

## 主界面入口（侧栏）

侧栏主区常见入口：

| 入口 | 用途 |
| --- | --- |
| 新会话 / 项目区 | 在工作目录中创建会话并执行任务 |
| 自动化 | 按计划单次或周期执行任务 |
| 知识库 | 导入并整理可长期检索的资料（界面可能带 BETA 标识） |
| 能力 | 技能、场景、MCP、插件、套装 |

**更多** 菜单中通常还有：

| 入口 | 用途 |
| --- | --- |
| 批量任务 | 同一提示处理多个文件夹 |
| 模型设置 | 跳转到设置中的模型配置 |
| Agent 设置 | 跳转到 Agent 配置 |
| 外观 | 跳转到外观设置 |

完整设置（Claw、知识库后台、应用环境、消息推送、Vetta Vivi 等）从侧栏 **设置** 进入。场景类型可在能力页管理；另有路由 `/scenes` 的场景专页，但不一定作为侧栏一级入口展示。

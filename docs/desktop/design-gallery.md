# 设计画廊（Design Gallery）功能介绍

> 系统插件 `vetta-ui-design` 的一部分，随 Vetta Desktop 发布。侧边栏「更多」→「设计」进入，也可以 pin 到左上方常驻（入口不再随工作模式隐藏，见 ADR-0046 的 2026-08 修订）。

## 它解决什么问题

设计稿散在各个项目里。你上周画的那套结算流程在哪个项目？叫什么名字？画到哪一步了？要回答这三个问题，你得挨个项目点进去、开画布、看一眼、退出来。

画廊把它们摆在一起：一个带设计稿的项目一张卡，封面就是这份设计画布最后的样子，点一下直接回到当初做它的那个会话。

## 卡片是怎么来的

画廊**主动收集**——不需要你注册任何东西。它扫侧边栏里的每个项目，凡是**项目根目录下**直接放着 `xxx.vetd/` 设计包的，就出一张卡。

两点需要知道：

- **只看项目根目录一层。** 你如果手动把设计包挪进 `designs/` 之类的子目录，画廊收不到（画布本身仍然找得到它）。这是为了让画廊在项目多、仓库大时也能秒开——递归扫描每一个项目的代价太高。
- **归档的项目不进画廊。** 归档的意思就是「从视野里拿走」。

### 旧格式会被自动升级

早期的设计文档是「`xxx.vetd` 文件 + `xxx.vetd.d/` 目录」两个条目，现在是单个 `xxx.vetd/` 目录。画廊每次加载和刷新时都会就地升级遇到的旧格式，你不需要做任何事——升级只是搬动文件，内容一个不少，中途断电重来也不会丢东西。`.vetdz` 分享包同样以 `.vetd` 结尾，画廊按内容识别，不会误拆。

## 卡片上是什么

```text
┌───────────────────────┐
│                       │
│    画布全景封面        │  ← 这份设计画布最后的样子
│                       │
├───────────────────────┤
│ 结算流程重做           │  ← 项目名
│ 3 份设计 · 2 天前      │  ← 设计份数（>1 才显示）与最近改动
└───────────────────────┘
```

右上角出现一个跳动的绿点，表示这个项目里**有会话正在跑**。

### 封面从哪来

画布会把各画框的位图按坐标拼成一张全景图存在本机——画布里画完停手一会儿就写一次，离开设计时再补最后一版。画廊如果发现某份设计还没有封面，也会自己拿缓存里的位图现补一张。所以：

- **只有从没在这台机器上打开过画布的设计（刚 clone、刚导入）才没有封面。** 卡面改用这份设计 `theme.css` 里的主色刷一个带名字的色块。进去开一次画布，回来就有真封面了。
- 封面只存在本机，不会写进你的项目目录，也不会进 git。
- 全景按**原比例**保存、卡面按固定比例裁切，所以画框横着排得很长的设计，卡面上只看得到中间一段。

### 一个项目有多份设计时

封面和时间取**最近改动的那一份**，info 区标出「N 份设计」。点卡片进去时也落在这一份上。

## 点卡片会发生什么

1. 跳进这个项目**最近一个还能续聊的会话**。只读的、或者已经被别的地方占用打不开的会话会被跳过；一个都没有时，落到这个项目的**新建会话页**。
2. 同时把设计画布铺开，并定位到卡面那份设计。

第 2 步是画廊特有的——平时只有「纯设计项目」才会自动展开画布，从画廊进来则一律展开：你点进来就是为了看这份设计。

## 新建与导入

工具栏右侧：

- **新建**：只问一个名字。会在你的工作区目录下建一个同名项目，然后进入这个项目的**新建会话页**，输入框里已经放好 `vetta-ui-design` 能力的 badge——接着写一句你想要什么（几屏、什么尺寸、什么风格），设计由 agent 建。这一步刻意不预先铺一份空设计：设计的结构由你的第一句话决定。设计建好后，画廊里自然就多出这张卡。
- **导入**：把 `.vetdz` 分享包**拖到画廊页面**，或者点「导入」选文件。会按包名建一个新项目，把设计解进去，同样直接进去。

## 卡片右键

| 菜单项 | 说明 |
| --- | --- |
| **导出分享包** | 导出成 `.vetdz`，落在设计包旁边。项目里有多份设计时会先让你选哪一份。导出要跑一次构建，会等几秒 |
| **在文件管理器中显示** | 在访达 / 资源管理器里定位项目目录 |
| **归档项目** | 从侧边栏和画廊里移除，**磁盘上的文件不动**，之后可以在项目列表里取消归档 |

## 搜索与排序

顶部搜索框按**项目名和设计名**过滤。排序固定为最近改动在前，与卡片上显示的时间同一个口径。

数据在每次进入画廊时重扫一次（每个项目一次目录读取，很便宜），也可以点「刷新」手动重扫。自己新建、导入、归档之后是就地更新，不会重扫。

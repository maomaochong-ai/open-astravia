# 架构决策记录（ADR）

## 编号规则

**编号一经分配即冻结，不重排、不复用、不回填。** 仓库内有 350+ 个文件（代码注释与文档正文）按编号引用 ADR，重编号会让这些引用全部失效。

由此带来两种看起来像"错误"、但实际是刻意保留的现象：

### 1. 编号空洞

| 编号 | 主题 |
| --- | --- |
| 0016 | Vetta Go 窗口配额服务 |
| 0017 | 固定槽位配额窗口 |
| 0019 | 技能管理字段以 DB 为真相源 |

| 0052 | 双权益来源与不可变窗口锚点 |
| 0056 | 图像生成经网关按积分计量 |

### 2. 编号重复

以下编号各有两个不同主题的文件，是并行开发时的历史产物，同样不做修正：

`0021` `0057` `0060` `0066` `0068` `0069`

引用这些编号时请连同标题一起写，避免歧义。

## 新增 ADR

取当前最大编号 +1。确认 `docs/adr/` 与上表的空洞编号都未占用该号。

# ADR-0159：模型选择器改为三栏面板

## 状态

已接受。

## 背景

模型选择器原先是「搜索框 + 按服务商分组的一条长列表」：几十个模型还能滚，上百个就
只能靠搜索，而搜索要求用户先记得模型名。参照实现在 0.5.73 把它改成了三栏
（服务商｜模型｜思考强度）并加了收藏。

本项目的模型数量来自用户自己配置的服务商，重度用户往往接三五个服务商、
每个几十个模型——正是单列长列表最难受的区间。同时「思考强度」原本塞在列表上方的一个
子菜单里，选完模型还要再点一次子菜单才能调档位，两步操作在两个不同的浮层里。

## 决策

### 1. 三栏结构

- 第一栏：服务商列表（**收藏**作为第一格，不是独立区域——收藏跨服务商，放进服务商栏
  才能与「当前看哪个服务商」共用一个选中位）；
- 第二栏：该服务商的模型列表，或搜索时全量命中（行尾标注来源服务商）；
- 第三栏：思考强度，**没有档位时整栏不渲染**（不占宽度、不留空列）。

搜索跨服务商平铺：用户此刻要的是「哪个模型叫这个名字」，而不是「这个服务商有没有它」。

### 2. 容器从 DropdownMenu 改为 Popover

内容已经是一个复合面板：服务商按钮列、可滚动的模型列表、思考档位列、搜索框、每行一个
星标按钮。放在 `DropdownMenuContent`（`role="menu"`）里有两个问题：

- ARIA 上不合法——菜单只能包含 `menuitem`；
- Radix 的方向键导航会把焦点困在「菜单项」之间，而面板里真正的交互是 Tab 在按钮之间走。

Popover 的语义是「带交互的附属面板」，正好对应它，且同样支持 Esc 与点击外部关闭。

顺带给 `PopoverContent` 补了 `portalContainer`（与 `DropdownMenuContent` 已有的同名
参数一致）：面板放在抽屉/对话框里时要挂到那些容器上，否则会渲染到 body、脱离父级滚动
边界。

### 3. 选择后的关闭行为

- 没有思考档位：选中即关闭（完成了一件完整的事）；
- 有思考档位：保持打开，让用户接着在右栏选强度。这是参照实现已有的行为，本次沿用。

### 4. 收藏只存本机

键 `astravia-model-favorites`，只存模型 key。收藏是「我这台机器常用的模型」，
跨设备同步反而会让别人的目录影响自己的菜单。存储不可用时退化为会话内有效。

### 5. 长列表虚拟滚动

超过 60 行才窗口化，行高固定（28px），用滚动位移直接算可见区间，不逐行测量。
几十行时窗口化的收益抵不上它带来的焦点与滚动锚点问题。


### 6. 玻璃材质与三栏几何（本轮修订）

三栏结构落地时面板外观停在参照实现的**中间态**：底色 60%、叠一层自绘描边与硬阴影。
参照实现随后自己推翻了那套写法，最终态是「只靠半透明与背景模糊，不叠任何自绘装饰」。
本节把这个结论写进合同，并补齐与参照实现一致的几何尺寸。

**材质**：面板内容面只有三个类名决定外观——

```text
bg-background/40  backdrop-blur-2xl  backdrop-saturate-150
```

- **不要**自绘 `border` / `dark:border-*`：基础浮层（`FLOATING_SURFACE_CLASS`）已经给了
  `rounded-2xl` ＋ 柔和投影 ＋ `dark:ring-1 dark:ring-white/10`，再画一圈描边就是两条边。
- **不要** `shadow-xl`：那是「用阴影弥补透明度」的写法，正是被推翻的那一版。
- **不要**渐变高光：同一次推翻里一起删掉了。

**几何**：三栏宽度与高度是一个整体，不能只改其中一栏。

| 部位 | 尺寸 | 说明 |
| --- | --- | --- |
| 面板高 | `h-[min(340px,60vh)]` | 固定高度，换服务商/改搜索词时面板不跳 |
| 第一栏（服务商） | `w-11`，图标 32×32 | 纯图标竖排，名称走 `title` + `aria-label`；收藏用星形实心图标。**收藏格常驻**——它只由「宿主是否提供收藏能力」决定，不因收藏为空而消失（与参照实现一致），空收藏点进去是专属空态 |
| 第二栏（模型） | `w-64`，顶部嵌搜索框 | 搜索框与列表同宽，横向层级才对得上；列表上下边缘用 mask 渐隐。**顶部还有一行服务商小标题**：搜索时显示「搜索结果」，否则显示当前服务商（或收藏）名——三栏里「第一栏点了哪个」必须能一眼对应到第二栏 |
| 第三栏（思考强度） | `w-32`，有档位才渲染 | 顶部一行 10px 小标题，与参照实现同款 |

模型详情浮层同步对齐：`w-64`、`p-3`、`backdrop-blur-xl backdrop-saturate-150`、
标题字号 13px，标签在上值在下且可选中复制。

**底栏**：`h-9`、上边框 `border-border/40`、`px-2`，两格 `justify-between`——
左侧是「怎么打开这个面板」的键帽提示，右侧是权限模式（沙箱 / 完全访问）。

- 键帽必须按**设置里的生效绑定**逐段渲染（`open-model-selector`，默认 `mod+p`），
  不能写死：写死会出现「改了键、提示还写着旧键」，而快捷键本身也走同一份配置。
- 权限模式在面板最右一格，因此要显式 `contentAlign="end"`（向右开会顶出面板右缘），
  且要 `showLabel`——底栏不是容器查询上下文，靠 `@[22rem]` 的默认规则只会出图标。
- 给错格的后果不是「难看一点」：权限模式跑到左侧时，右侧空着、左侧挤着键帽与模式名，
  与参照实现的读法（左提示、右控件）完全不同，用户会以为这里是两个无关控件。

**圆角**：面板的外观类必须落在**自己持有圆角**的那层元素上。`PopoverContent` 用 `asChild` 时，
Radix 的 Slot 只是把 className 拼接到子元素上（不经 tailwind-merge 去重），
`rounded-2xl` 与内层的 `rounded-[inherit]` 会同时出现在一个元素上，`inherit` 从 portal 容器
继承到 0——面板变成直角，而且只看类名列表完全看不出问题。因此这里不用 `asChild`：
Popover 自己出那层带 `rounded-2xl` 的面，内层再 `rounded-[inherit]`。

**收藏格常驻，空收藏有专属空态。** 收藏能力由宿主总是提供（`favoriteKeys` 是必填参数），所以第一栏的
收藏格不因收藏为空而消失。此前本仓把它写成了 `favoriteModels.length > 0` 才推入服务商列，
于是没收藏时第一栏没有收藏入口——与参照实现不一致（它的 rail 收藏格只由「是否提供收藏能力」决定）。
空收藏时点进去显示星标 + `favoritesEmpty`（「还没有收藏的模型」），而不是搜索的「未找到模型」。

**星标常驻，而不是悬停才出现。** 收藏是「我这台机器常用的模型」，与「选中」一样是行的一等状态，
不该藏起来；已收藏的用实心金星（`text-amber-500` + `solar--star-bold`），未收藏的用浅色空星
（`text-muted-foreground` + `solar--star-linear`），悬停加深。这与上一版「未收藏时 `display:none`、
悬停才出现」不同——那版把收藏降级成了悬停彩蛋，用户不知道「点这里能收藏」。

**虚拟窗口的自适应**：面板高度固定后，列表实际可视高度还取决于搜索框与底栏。面板用
`ResizeObserver` 量一次 `clientHeight` 作为虚拟窗口高度，量不到（jsdom、首帧）时回落到
宿主给的兜底值——否则行数与可见区间会按错误的高度算，滚到底之后仍有一段空白。

**为什么第一栏从「116px 带名字」改成「44px 纯图标」**：名字这一列会把模型栏挤窄，
而服务商图标本身已经能认；拿不准时悬停有 `title`，屏幕阅读器有 `aria-label`。

## 备选方案

- **保留单列，只加收藏与分组折叠**：成本最低，但没有解决「换服务商等于滚动」这件事，
  而这是模型多时最常做的动作。
- **保留 DropdownMenu，把三栏塞进菜单项**：ARIA 不合法，且星标按钮与搜索框都不是菜单项，
  键盘导航会失效。
- **弹出独立对话框**：模型选择是高频轻量操作，弹窗会打断输入流的上下文。

## 后果

- 正面：找模型从「滚动 + 读」变成「点 + 读」；思考档位与模型在同一面板，少一层浮层；
  常用模型不必每次现找。面板宽度从 16rem 放到 34rem，三栏才排得开。
- 代价：面板更宽，窄窗口下会退化为「两栏 + 收缩」，需要 `max-w` 兜底（已用
  `min(34rem, 100vw - 2rem)`）；`PopoverContent` 多了一个参数要维护。
- 已知限制：面板的视觉（三栏在 320px 窄屏下的排布）**未实机验证**——本机 dev 壳没有
  开远程调试端口，无法截图核对；纯逻辑与组件行为有 22 条用例覆盖。
- 本轮新增的材质与几何约束同样只有组件级用例（`ModelSelectorView.test.tsx` 断言
  `bg-background/40`、`backdrop-blur-2xl`、且不含 `shadow-xl` / `dark:border`），
  像素级观感仍需在真实桌面里验收。

FAQ

Questions, answered.

Is it really free? +

Yes — the app is open source. Bring your own API key for OpenAI, Anthropic, Google, or another supported provider, or run a local model with Ollama. You pay your model provider directly and nothing to us.

Where do my passwords and tokens live? +

On your device, in the app's local secret store. The optional cloud account only brokers the OAuth handshake — tokens are handed straight to your machine and never stored in the cloud.

Will it do things without asking me? +

Only what you've allowed. Anything consequential — sending an email, posting to Slack, running a command — lands as a check-in you approve, in the app or from Slack. You choose how independently it’s allowed to act.

Will the security coworkers change my infrastructure? +

No. Cloud access is read-only, and nothing is ever applied directly — every fix lands as a pull request you review and merge. The security coworkers drive the scanners you already trust rather than replacing them, and secret values never appear in a transcript.

Do I need an account? +

No. Everything works while signed out, using API keys and tokens you provide. A free OpenWorker account adds one-click connections to tools such as Slack, where vendor restrictions require OpenWorker to manage the sign-in flow.

Which models can I use? +

OpenAI, Anthropic, and Google models through your own API keys; open-weight models such as Kimi, GLM, and DeepSeek through supported providers; or local models through Ollama. You can switch models per task, even mid-conversation.

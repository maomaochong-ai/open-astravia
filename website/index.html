STORY · 产品故事

看见工作如何在星轨中向前推进。

从一句需求到交付成果——每一步都在你眼前展开：计划、执行、审阅、沉淀，全部留在本机。

01 · 提出需求

交给星轨材料，告诉它最终目标

选择“网站发布”工作流，附上已确认的材料文件，再用一句话说明希望交付的结果。

✓输入已准备 · 3 个源文件

02 · 生成计划

让计划变成看得见的工作过程

智能体读取材料、生成简明计划，并在可检查的任务列表中逐步推进。

✓任务已完成 · 8 项

03 · 执行任务

工具与数据在同一处流转

调用 SQL 工作台、批量任务、文件读写与知识库——执行过程留痕可见，随时可以介入调整。

✓工具调用 · 全部成功

04 · 审阅交付

审阅真正的结果，而不是聊天记录

交付的页面、报表与文件在应用内直接预览；不满足就继续迭代，满意了才收下。

✓交付完成 · 已生成预览

05 · 沉淀复用

刚交付的文件，收进知识库

把工作成果收纳到本机知识库，下次同类任务直接引用——一切默认都在 ~/.astravia。

✓已收纳 · 数据留在本机

PRODUCTS · 能力

一个应用，八项能力。

对话、数据库、批量任务与扩展生态在同一个窗口里协作——不需要额外客户端，不依赖任何外部服务。

01

对话与工作区

消息流、工具调用与生成结果同屏可见；文件在应用内直接预览（PDF、Word、PPT、表格、图片、音视频、SVG），扫描版 PDF 支持离线 OCR。

  • 会话
  • 文件预览
  • 离线 OCR
02

数据库工作台

内置连接管理与 SQL 工作台：表浏览、多标签查询、历史记录、CSV/JSON 导出。AI 可直接在对话中查数，写操作分级授权，生产连接默认只读。

  • SQL
  • 40+ 数据库
  • AI 查数
03

批量任务

一条指令对多个目录批量执行；任务按「项目 + 任务」组织，可运行、可重试，进度实时可见。

  • 批处理
  • 可重试
04

定时调度

内置 Cron 调度，任务在系统托盘后台运行，执行历史随时可查。

  • Cron
  • 托盘常驻
05

通知与远程控制

批量 / 定时任务完成或异常时推送到飞书、钉钉机器人；手机 IM 可遥控本机 Agent，凭据本地加密。

  • 飞书
  • 钉钉
  • 遥控
06

扩展生态

从任意 GitHub 仓库安装 Skill、MCP Server、插件与能力包；本地文档加工成可检索知识库，全程不出本机。

WORKFLOW · 快速上手

四步，从下载到自动化。

  1. 01

    下载安装

    从 Releases 下载 macOS / Windows / Linux 安装包，双击即装，无需注册账号。

  2. 02

    配置模型

    设置中选择服务商，填入你自己的 Key；请求直连服务商，密钥只存本机钥匙串。

  3. 03

    开始对话

    新建项目写代码、整理文档、处理文件；要查数据时连上数据库，用自然语言直接问。

  4. 04

    自动化收尾

    重复性工作交给批量任务与定时调度，完成时通过飞书 / 钉钉机器人收到通知。

MODELS · 模型

用你自己的模型。
用你自己的 Key。

内置多家服务商预设——预设只含接口地址与 API 类型，不含任何 Key。填入 Key 后立即拉取该账号可用模型，之后每 12 小时后台同步；价格与能力元数据由 models.dev 补齐，随包带快照兜底。

PRIVACY · 隐私

你在本机工作，
数据就留在本机。

没有云端

无登录、无账号、无订阅。模型密钥（BYOK）由你配置，请求直连服务商。

没有遥测

不收集崩溃报告与使用统计；任何出站请求都由你的配置明确触发。

数据在本机

会话、工作区、知识库、数据库连接默认都在 ~/.astravia，不离开你的机器。

只在以下情况联网（全部由你的配置决定）：

  • LLM 推理 —— 你配置的服务商；不配 Key 即不发生
  • 模型元数据 —— models.dev 公共目录；失败回退随包快照
  • 能力市场 —— 你添加的 GitHub 仓库；不加来源即不发生
  • 自动更新 —— 更新源由应用配置决定；不配即不检查
  • MCP / 插件 / Webhook / IM —— 由你安装的扩展与凭据决定

没有遥测，没有崩溃上报，没有使用统计。

FAQ · 常见问题

常见问题。

需要注册账号吗？

不需要。星轨没有账号体系，不登录、不订阅、不收费——它是一款本地运行的开源应用。

我的数据存在哪里？

默认都在本机 ~/.astravia：会话、工作区、知识库、数据库连接，全部不离开你的机器。

支持哪些模型？

内置 Claude、OpenAI、DeepSeek、Kimi、Gemini、Grok、Qwen、Z.ai 等预设，也支持任何 OpenAI 兼容端点——包括 Ollama、vLLM、LM Studio 等本地推理。只需要你自己的 Key。

必须联网才能用吗？

不需要。联网只发生在你配置的范围内：不配置服务商 Key 就不会有推理请求；使用本地推理端点可以完全离线。

如何更新到新版本？

自动更新由应用内配置决定（基于 electron-updater）；也可以随时到官网下载最新安装包覆盖安装。

星轨与 Vetta 是什么关系？

星轨是独立自研的开源项目，不依赖任何既有产品代码。Agent 内核与桌面宿主均由我们自主设计与维护，并持续独立演进。

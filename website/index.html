产品故事

真实功能，一屏一屏地看

每个节点都是星轨 Astravia 桌面端的真实功能页面——滚动左侧时间线，右侧窗口随之切换。

核心能力

一个应用，八项能力。

对话、数据库、批量任务与扩展能力，在同一窗口协作——无需额外客户端，不依赖外部服务。

01

对话与工作区

消息流、工具调用与结果同屏可见；PDF、Word、PPT、表格、图片、音视频、SVG 等文件应用内直接预览，扫描版 PDF 支持离线 OCR。

  • 会话
  • 文件预览
  • 离线 OCR
02

数据库工作台

内置连接管理与 SQL 工作台：表浏览、多标签查询、历史记录、CSV/JSON 导出。AI 对话中直接查数，写操作分级授权，生产连接默认只读。

  • SQL
  • 40+ 数据库
  • AI 查数
03

批量任务

一条指令批量执行多个目录；任务按「项目 + 任务」组织，可运行、可重试，进度实时可见。

  • 批处理
  • 可重试
04

定时任务

内置 Cron 调度，任务在系统托盘后台运行，执行历史随时可查。

  • Cron
  • 托盘常驻
05

通知与远程控制

批量 / 定时任务完成或异常时推送到飞书、钉钉机器人；手机 IM 可遥控本机 Agent，凭据本地加密。

  • 飞书
  • 钉钉
  • 遥控
06

快速上手

四步，从下载到自动化。

  1. 01

    下载安装

    从 Releases 下载 macOS / Windows / Linux 安装包，双击即装，无需注册账号。

  2. 02

    配置模型

    设置中选择服务商，填入你自己的 Key；请求直连服务商，密钥只存本机钥匙串。

  3. 03

    开始对话

    新建项目写代码、整理文档、处理文件；要查数据时连上数据库，用自然语言直接问。

  4. 04

    自动化收尾

    重复性工作交给自动化与批量任务，完成时通过飞书 / 钉钉机器人收到通知。

模型

用你自己的模型。
用你自己的 Key。

内置多家服务商预设——只含接口地址与 API 类型，不含任何 Key。填入 Key 立即拉取可用模型，之后每 12 小时后台同步；模型能力与价格由 models.dev 补齐，随包带快照兜底。

隐私承诺

你在本机工作，
数据就留在本机。

没有云端

无登录、无账号、无订阅。模型密钥（BYOK）由你配置，请求直连服务商。

没有遥测

不收集崩溃报告与使用统计；任何出站请求都由你的配置明确触发。

数据在本机

会话、工作区、知识库、数据库连接默认都在 ~/.astravia，不离开你的机器。

只在以下情况联网（全部由你的配置决定）：

  • LLM 推理 —— 你配置的服务商；不配 Key 即不发生
  • 模型元数据 —— models.dev 公共目录；失败回退随包快照
  • 能力市场 —— 你添加的 GitHub 仓库；不加来源即不发生
  • 自动更新 —— 更新源由应用配置决定；不配即不检查
  • MCP / 插件 / Webhook / IM —— 由你安装的扩展与凭据决定

没有遥测，没有崩溃上报，没有使用统计。

常见问题

常见问题。

需要注册账号吗？

不需要。星轨没有账号体系，不登录、不订阅、不收费——它是一款本地运行的开源应用。

我的数据存在哪里？

默认都在本机 ~/.astravia：会话、工作区、知识库、数据库连接，全部不离开你的机器。

支持哪些模型？

内置 Claude、OpenAI、DeepSeek、Kimi、Gemini、Grok、Qwen、Z.ai 等预设，也支持任何 OpenAI 兼容端点——包括 Ollama、vLLM、LM Studio 等本地推理。只需要你自己的 Key。

必须联网才能用吗？

不需要。联网只发生在你配置的范围内：不配置服务商 Key 就不会有推理请求；使用本地推理端点可以完全离线。

如何更新到新版本？

自动更新由应用内配置决定，也可以随时到官网下载最新安装包覆盖安装。

星轨的独立自研是指什么？

星轨是完全独立自研的开源项目，不依赖任何既有产品代码。Agent 内核与桌面宿主均由我们自主设计与维护，并持续独立演进。

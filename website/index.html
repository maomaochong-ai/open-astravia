开始之前，
先问清楚

关于隐私、方案与用量的真实问题，用产品本身来回答。

什么是星轨 Astravia？

一套开源、本地优先的 AI Agent 桌面应用：对话、编码、文档、数据库、批量任务、定时任务与设计画布都在同一个工作区里，模型与密钥由你自己配置。

星轨是开源的吗？

是。Apache-2.0 许可，客户端与服务端的可开源部分都在 GitHub 上，可查看、可自托管、可二次开发。

星轨能扩展哪些能力？

插件与技能能给应用加面板、加工具，MCP 能接外部服务；三者都能自己写，也能从能力市场装。官方与社区并行，装不装由你决定。

我的数据安全吗？

会话、工作区、知识库与数据库连接默认都在本机 ~/.astravia，密钥存系统钥匙串；没有遥测、没有崩溃上报，出站请求只发生在你配置的服务商与插件上。

我该选哪个方案？

个人直接用开源版：下载即装，功能齐全，不收费也不用注册。需要数据驻留、内部系统对接或定制插件时，到 Issues 说明场景，我们再谈部署范围。

超出使用限制会怎样？

没有额度这回事。星轨不代理推理，也不从中计费——你直接调用自己的模型服务商，用多少、花多少都由那边的账户决定。到额时限制来自服务商，而不是这个应用。

插件能做什么？

扩展应用本身，而不只是多一个工具：新增侧栏面板、活动区标签页与命令，接入数据库、外部 API 或内部系统，并把结果留在同一份工作区记录里。

IPA · 需自备 Apple ID 签名

  1. 把 IPA 下到电脑上。
